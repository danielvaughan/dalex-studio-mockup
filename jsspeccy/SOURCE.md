# JSSpeccy source

JSSpeccy 3.2 by Matt Westcott, GPL-3.0; see COPYING and jsspeccy.js.LICENSE.txt.

`source-v3.2.tar.gz` is the upstream v3.2 source from https://github.com/gasman/jsspeccy3/tree/v3.2.
`source-studio.tar.gz` includes the two Studio patches in readable source form. Build instructions and package scripts are inside the archive. PATCH.md documents the identical changes applied to the vendored distribution. The built emulator and ROM/tape-loader assets are reused from the existing Studio harness. These archives and license notices are distributed beside the runnable files.
